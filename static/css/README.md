# 📋 โครงสร้าง CSS ที่แยกตามหน้า

ไฟล์ CSS ทั้งหมดได้ถูกแยกออกจากกัน โดยจัดเรียงตามหน้าและส่วนประกอบของแอปพลิเคชัน

## 📂 รายชื่อไฟล์ CSS

| ไฟล์ | คำอธิบาย |
|-----|---------|
| **main.css** | ไฟล์หลักที่นำเข้า CSS ทั้งหมด (ใช้ไฟล์นี้ในเท็มเพลต HTML) |
| **variables.css** | ตัวแปร CSS สี ขนาด และสไตล์พื้นฐาน |
| **login.css** | สไตล์สำหรับหน้าเข้าสู่ระบบ (login.html) |
| **layout.css** | สไตล์เลย์เอาต์แอป: แถบด้านข้าง แถบนำทาง เนื้อหาหลัก |
| **dashboard.css** | สไตล์สำหรับแดชบอร์ดและการ์ดสถิติ (dashboard.html) |
| **tables.css** | สไตล์สำหรับตาราง การ์ดแสดงเนื้อหา (request_list.html) |
| **components.css** | สไตล์ส่วนประกอบทั่วไป: ป้าย ไทม์ไลน์ การแจ้งเตือน ขั้นตอนการไหล |
| **security.css** | สไตล์สำหรับหน้าประเมินความปลอดภัย (security_checkin.html) |
| **approval.css** | สไตล์สำหรับหน้าอนุมัติ (approval.html) |
| **detail.css** | สไตล์สำหรับการแสดงรายละเอียด (request_detail.html) |
| **responsive.css** | สไตล์ตอบสนองและสไตล์การพิมพ์ |

## 🔄 วิธีการใช้งาน

### ในเท็มเพลต HTML ให้แทนที่:

```html
<!-- เดิม -->
<link rel="stylesheet" href="{{ url_for('static', filename='css/style.css') }}">

<!-- เป็น -->
<link rel="stylesheet" href="{{ url_for('static', filename='css/main.css') }}">
```

## 💡 ข้อมูลเพิ่มเติม

- ทุกไฟล์มีคอมเมนต์ภาษาไทยอธิบายรายละเอียด
- `main.css` จะทำการนำเข้า CSS ทั้งหมดโดยอัตโนมัติ
- คุณสามารถแก้ไขสไตล์ของแต่ละหน้าแยกกันได้อย่างอิสระ
- ตัวแปร CSS ใน `variables.css` สามารถใช้ทั่วทั้งแอป

## 🗑️ การลบ style.css เดิม

หลังจากตรวจสอบว่าทุกอย่างทำงานได้ดี คุณสามารถลบ `style.css` เดิมได้
